# Privacy Policy — IIBA Eligibility Checker

_Last updated: 30 October 2026_

The IIBA Eligibility Checker is published by Techcanvass. It is available as a browser extension
(Chrome, Microsoft Edge, Firefox), a WordPress plugin, a Discord bot and a web page.

## What we collect

**Nothing.** The hours, dates and answers you enter are processed on your own device (browser extension,
WordPress plugin, web page) or in memory for the length of a single command (Discord bot). They are not
stored, logged, sold or sent to Techcanvass or anyone else.

- No accounts, cookies, analytics or tracking inside the extension.
- The browser extension requests no browser permissions.
- The Discord bot replies privately ("ephemeral" messages) and does not read other messages.

## Network requests

The tool may download a public rules file (the current IIBA eligibility thresholds) from a Techcanvass
web address. That request contains no information about you.

Links to Techcanvass course pages include campaign tags (e.g. `utm_source=browser_extension`) so we can
tell which version of the tool a visit came from. These tags do not identify you.

## WordPress sites

Website owners who install the WordPress plugin are responsible for their own site's privacy policy. The
plugin itself stores only its two settings (rules URL and UTM tags) in the site's database.
